# Segurança

Não publique vulnerabilidades, tokens, chaves de assinatura ou outros segredos em issues públicas.

Para relatar um problema de segurança, use o recurso **Private vulnerability reporting** do GitHub, quando habilitado, ou contate o mantenedor por um canal privado previamente acordado. Inclua impacto, reprodução e uma sugestão de mitigação, se disponível.
